# Krümmung aus Gitter (veraltet)

Die Krümmung des Gitterbäckers erzeugt eine Krümmungstextur aus hochpolaren Gittern. Er ist langsamer als der Basiskrümmungs-](../../bakers-settings/curvature/curvature.md)-Bäcker von [, liefert jedoch genauere Ergebnisse.

**Verfügbar in:**

* Substance Designer
* Substance Automation Toolkit

>[!NOTE]
>
> Seit Substance Designer 2019.3 ist dieser Bäcker veraltet und wir empfehlen, stattdessen die neue [Krümmung von mesh](../../bakers-settings/curvature-from-mesh/curvature-from-mesh.md)-Bäcker zu verwenden.

## Parameter

| *Parameter* | *Beschreibung* |
| --- | --- |
| **Intensität** | Legt die Stärke der Krümmungsdetails fest. Dieser Parameter ist deaktiviert, wenn **Soft Saturate** aktiviert ist. |
| **Weich** **Sättigung** | Wenn diese Option aktiviert ist, werden die Krümmungsdetails weicher. |
| **Bereich maximieren** | Wenn diese Option aktiviert ist, werden die Krümmungsdetails in die Texturbereichskapazität eingepasst. Das bedeutet, dass sehr starke Werte als Maximum definiert werden und alle anderen Werte entsprechend diesem Extrem skaliert werden. |
