# Opazitätsmaske aus Mesh

Die Deckkraftmaske von mesh baker berechnet eine Textur, bei der verpasste Strahlen in ein binäres Graustufenbild konvertiert werden. Diese Textur wird im Allgemeinen als Deckkraftmap verwendet.

Die Textureigenschaften sind wie folgt definiert:

* Schwarze Werte stellen leere Bereiche dar.
* Weiße Werte stellen konvexe Bereiche dar.

**Verfügbar in:**

* Painter
* Designer
* Automatisierungs-Toolkit

## Parameter:

Dieser Bäcker hat keine spezifischen Parameter.
