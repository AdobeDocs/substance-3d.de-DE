# Einrichtung

## Voraussetzungen

Cinema 4D R16 oder höher ist erforderlich. Alle Produktversionen außer Cinema 4D Lite werden unterstützt.

Substance-Dateien können mit [Substance Designer](https://www.allegorithmic.com/products/substance-designer) erstellt werden.

## Installation

## Windows

1. Cinema 4D sollte während der Installation nicht ausgeführt werden.
1. Führen Sie das Paket zur Selbstinstallation aus.
1. Wählen Sie den Zielordner aus bzw. überprüfen Sie ihn. Dies sollte der Ordner sein, in dem Cinema4D installiert wurde, nicht der Unterordner für Plug-ins.
1. Klicken Sie auf Installieren.
1. Nach erfolgreicher Installation haben Sie die Möglichkeit, Cinema 4D zu starten.

## MAC OS X

1. Cinema 4D sollte während der Installation nicht ausgeführt werden.
1. Legen Sie die Cold-Datei im Ordner &quot;Cinema 4D plugins&quot; ab.
1. Starten Sie Cinema 4D wie gewohnt.
