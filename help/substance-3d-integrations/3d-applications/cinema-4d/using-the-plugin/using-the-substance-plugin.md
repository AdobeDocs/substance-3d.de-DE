# Verwenden des Substance-Plug-ins

Das Substance-Plug-in befindet sich im Menü Cinema 4D-Plug-ins .

![](../../../assets/cinema-4d-1.png){width="500px"}

## Element laden...

So laden Sie Substance-Assets in Ihre Szene. Es können nur Substance-Archive (.sbsar) geladen werden. Wenn der Substance Asset Manager nicht bereits angezeigt wird, wird er nach erfolgreichem Import der Substance automatisch geöffnet. Dieser Befehl befindet sich auch im Substance Asset Manager.

Beim Importieren werden Sie möglicherweise gefragt, ob die Substance in Ihren Projektordner kopiert werden soll.

![](../../../assets/cinema-4d-2.png){width="500px"}

* Wenn du mit &quot;Nein&quot; antwortest, wird ein absoluter Pfad zur Substance in deiner Szene gespeichert.
* Wenn Sie auf &quot;Ja&quot; antworten, wird die Substance in den Text-Unterordner Ihres Projekts kopiert und in Ihrer Szene wird sie nur mit Dateiname referenziert.

Diese Eingabeaufforderung wird nur einmal pro Import angezeigt (z. B. beim Ziehen und Ablegen mehrerer Substance aus dem Explorer oder Finder).
