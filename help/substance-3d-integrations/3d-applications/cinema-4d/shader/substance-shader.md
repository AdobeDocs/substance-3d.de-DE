# Substance Shader

Ein Substance-Shader ist die Verknüpfung zwischen einem Substance-Asset und einem Cinema 4D-Material.

Der Substance-Shader befindet sich im Auswahlmenü des Cinema 4D-Material-Editors, wie im folgenden Screenshot gezeigt:

![](../../../assets/cinema-4d-6.png){width="500px"}

Nachdem Sie einen Substance-Shader manuell hinzugefügt haben, verfügt er über kein verknüpftes Substance-Asset. Das Material sieht wie folgt aus: Wenn es gerendert wird, sieht es wie im Bild auf der rechten Seite aus:

![](https://helpx-prod.scene7.com/is/image/HelpxProd/cinema-4d-7?$png$&jpegSize=300&wid=1506){width="500px"}

Um auf die Parameter des Substance-Shaders zuzugreifen, können Sie entweder auf den kleinen Pfeil oben links oder auf das Vorschaubild des Shaders klicken.

![](../../../assets/cinema-4d-8.png){width="500px"}

## Parameter

Der Substance-Shader verfügt über zwei Parameter:

* **Asset:** Hier können Sie ein Substance-Asset aus dem Substance Asset Manager ablegen, um es mit dem Shader zu verknüpfen. Mit anderen Worten, ein Substance-Asset wird mit einem Cinema 4D-Materialkanal verknüpft.
* **Kanal:** Wählen Sie den Ausgabekanal der verknüpften Substance aus.
