# Deinstallieren des Add-ons

Um das Add-on zu deinstallieren, navigieren Sie zu Bearbeiten > Voreinstellungen > Add-ons und erweitern Sie den Abschnitt für das Add-on.

1. Entfernen Sie zuerst die Integrationstools mit der Schaltfläche **Tools deinstallieren**.
1. Entfernen Sie dann die Add-On-Dateien mit der Schaltfläche **Entfernen**

>[!NOTE]
>
> Wenn die Substance Integration Tools manuell entfernt werden müssen, löschen Sie den Ordner Substance3DIntegrationTools aus dem folgenden Verzeichnis
> 
> * **Windows**: C:\Users\(Benutzername)\AppData\Roaming\Adobe
> * **Mac**: /Users/(Benutzername)/Library/Application Support/Adobe/Substance3DIntegrationTools
> * **Linux**: /home/(Benutzername)/Adobe/Substance3DIntegrationTools
