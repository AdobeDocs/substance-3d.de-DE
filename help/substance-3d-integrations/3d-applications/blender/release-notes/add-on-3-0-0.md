# Add-on 3.0.0+

**Add-on 3.1.0**.*Veröffentlicht am: 20. Oktober 2026*

**Blender-Add-On:**

* &lbrack;Fehler&rbrack; Fester Bibliothekspfad funktioniert nicht
* &lbrack;Fehler&rbrack; Kontextproblem im Multithreading behoben, sodass SBSAR nicht geladen/aktualisiert werden konnte
* &lbrack;Fehler&rbrack; Das Exportformat für feste Texturen wird ignoriert.
* &lbrack;Performance&rbrack; Verschiedene Leistungsverbesserungen

**Substance-Integrationstools (Substance Remote Engine):**

* &lbrack;Feature&rbrack; Aktualisiert auf Substance Engine 9.6.1
* &lbrack;Performance&rbrack; Aktualisierte Abhängigkeiten und mehrere Leistungsverbesserungen

**Add-on 3.0.1**.*Veröffentlicht am: Februar 2026*

**Blender-Add-on:**

* &lbrack;Fixiert&rbrack; Parameter &quot;min/max&quot; funktionieren nicht
* &lbrack;Fixiert&rbrack; Physische Größe funktioniert nicht mit benutzerdefinierter Szene-Skalierung
* &lbrack;Fixiert&rbrack; Physische Größe funktioniert nicht mit nicht metrischen Systemeinheiten
* &lbrack;Fixiert&rbrack; Clearcoat-Karten funktionieren nicht mit dem Mixer 4+
* &lbrack;Fixiert&rbrack; Klarlack-Farbkarte auf Shader fehlt
* &lbrack;Fixiert&rbrack; Falsche Bezeichnung in AddOn-Definition
* &lbrack;Fixiert&rbrack; Beim Substance wird der SRE-Wert zufällig Absturz ( mit den Werten für &quot;float4&quot;).
* &lbrack;Fixiert&rbrack; Bildeingaben werden in der Parameterliste nicht angezeigt
* &lbrack;Fixiert&lbrack; Bildeingaben funktionieren nach dem Schließen und erneuten Öffnen des Mischers nicht

**Substance-Integrationstools (Substance Remote Engine):**

* Upgrade auf Version 3.0.1
* C++11 ABI für neue Linux-Kompilierung entfernt
