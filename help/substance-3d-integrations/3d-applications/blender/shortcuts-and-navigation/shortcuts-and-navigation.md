# Tastaturbefehle und Navigation

Eine Liste der Tastaturbefehle finden Sie unten in den Add-on-Voreinstellungen. Die Tastenbelegungen für jeden Tastaturbefehl können angepasst werden, indem Sie die gewünschten Tasten in das Feld Taste eingeben. Strg, Umschalt und Alt können auch für jeden Tastaturbefehl aktiviert werden.

Die Standardtastenbindungen sind:

* **Menü mit schwebenden Elementen** - STRG + UMSCHALT + U
* **SBSAR laden** - STRG + UMSCHALT + L
* **Aktuelles Material anwenden** - STRG + UMSCHALT + U
