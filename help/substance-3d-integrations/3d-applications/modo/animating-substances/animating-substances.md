# Substance animieren.

## Animieren von SubstanceTextures

Die erweiterten Parameter können wie jeder andere Kanal in MODO animiert werden. Wenn Sie die Substance Engine-Zeitvariable ($time) zum Animieren eines Stoffes verwenden, können Sie auf diese spezifische Engine-Variable auf den Benutzerkanälen des Substance zugreifen.\
Durch Animieren dieses Kanals können Sie die Animation steuern, wenn die Substance mit der Variablen $time erstellt wurde.
