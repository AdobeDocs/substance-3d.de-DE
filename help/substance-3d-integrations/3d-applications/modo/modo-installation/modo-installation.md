# Modo-Installation

Um das Plugin zu installieren, ziehen Sie einfach die LPK-Datei in MODO. Wenn Sie weder ein Kit noch das MODO-Inhaltspaket installiert haben, wird möglicherweise ein Dialogfeld angezeigt, in dem Sie aufgefordert werden, die entsprechenden Ordner zu erstellen. Sobald das Kit installiert ist, wird oben rechts in der MODO-Benutzeroberfläche eine Substance-Schaltfläche angezeigt.
