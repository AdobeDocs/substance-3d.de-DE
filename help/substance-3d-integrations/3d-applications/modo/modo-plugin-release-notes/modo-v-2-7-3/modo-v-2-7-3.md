# Modo v. 2.7.3

Veröffentlicht am 7. April 2020

Hinzugefügt:

* Unterstützt MODO 14
* Wertausgaben in der Unterstützung von Benutzerkanälen
* Quellcode auf Adobe Git verfügbar
* Mac-Version kompatibel mit Catalina

Problembehebungen:

* Mac-Versionsprobleme, die durch die Funktion Senden an - entfernt verursacht wurden, wobei Pläne für eine neuere Version umgestaltet werden müssen

Unterstützt Modo-Versionen 11.0 und höher
