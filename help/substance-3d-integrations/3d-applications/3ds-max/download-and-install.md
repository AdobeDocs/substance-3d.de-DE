# Herunterladen und installieren

Die neueste Version des Plug-Ins wird nativ von Autodesk mit der neuesten kompatiblen Version von 3ds Max vertrieben. Wenn Sie einen bestimmten Build für eine ältere Version benötigen, finden Sie die Download-Links unten.

* **Download für Autodesk 3ds Max 2027:** <https://www.adobe.com/go/substance3d-3dsmax-win-latest>
* **Download für Autodesk 3dsMax 2026:** <https://www.adobe.com/go/substance3d-3dsmax-win-2026>
* **Download für Autodesk 3dsMax 2025:** <https://www.adobe.com/go/substance3d-3dsmax-win-2025>
* **Download für Autodesk 3dsMax 2024** (Plug-in-Version 3.1.0.): 2<https://www.adobe.com/go/substance3d-3dsmax-win-2024>
