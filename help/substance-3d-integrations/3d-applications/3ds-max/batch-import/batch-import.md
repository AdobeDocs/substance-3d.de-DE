# Stapelimport

Mit dem Stapelimport können Sie mehrere .sbsar-Substance-Dateien im Stapel importieren.

1. Gehen Sie zu den Substance-Einstellungen oben auf der 3ds Max-Benutzeroberfläche und wählen Sie Substance Batch-Import.
1. Wählen Sie die .sbsar-Dateien aus, die Sie importieren möchten.
