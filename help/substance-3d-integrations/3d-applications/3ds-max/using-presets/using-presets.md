# Verwenden von Vorgaben

Substance-Dateien können eingebettete Vorgabedateien enthalten. Wenn eine Substance über eine eingebettete Voreinstellungsdatei verfügt, wird sie im Fenster &quot;Substance-Vorgaben&quot; angezeigt. Sie können auch eigene Vorgaben erstellen, die auf den Einstellungen basieren, die Sie für die Substance-Parameter ausgewählt haben.

![](../../../assets/max9.png)

1. &quot;Vorgabe erstellen&quot; erstellt eine neue Vorgabe basierend auf den Parametereinstellungen, die Sie für den Substance in 3ds Max festgelegt haben.
1. &quot;Vorgabe importieren&quot; importiert eine Vorgabedatei (.sbsprs).
1. &quot;Vorgabe speichern&quot; speichert die Parameterwerte für die aktuell ausgewählte Vorgabe.
1. Die ausgewählte Vorgabe exportieren exportiert die Vorgabe in eine Vorgabedatei (.sbsprs).
1. Mit Alle Vorgaben entfernen werden die Vorgaben in der Vorgabenliste entfernt.
1. Mit Ausgewählte Vorgabe entfernen wird nur die ausgewählte Vorgabe entfernt.
