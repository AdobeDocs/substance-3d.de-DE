# Installation

Das Substance in Maya-Plugin wird auch offiziell im Maya 2022/2020-Installationsprogramm installiert. Diese Option ist standardmäßig für die Installation aktiviert.

>[!NOTE]
>
> **Mai 2022**
> 
> **Windows**: C:\Program Files\Allegorithmic\Adobe Substance 3D für Mai\2022\
> **MacOS**: /Applications/Allegorithmic/Adobe Substance 3D for Maya/2022\
> **Linux**: /opt/Allegorithmic/Adobe Substance 3D für Mai 2022

>[!NOTE]
>
> **Mai 2020**
> 
> **Windows**: C:\Program Files\Allegorithmic\Adobe Substance 3D für Mai\2020\
> **MacOS**: /Applications/Allegorithmic/Adobe Substance 3D for Maya/2020\
> **Linux**: /opt/Allegorithmic/Adobe Substance 3D für Mai 2020

Darüber hinaus kann das Installationsprogramm für die neuesten Versionen des Plug-ins von der Seite [Adobe Substance 3D für Mai](https://substance3d.adobe.com/plugins/substance-in-maya/) heruntergeladen werden.
