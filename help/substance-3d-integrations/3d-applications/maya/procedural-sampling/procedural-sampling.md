# Verfahrensauswahl

Mit den Einstellungen für prozedurales Sampling können Sie steuern, in welcher Größe das Plug-In prozedurale Texturen wie Browninan, Noise, Fractal, Mandelbrot usw. aufnimmt. Diese Einstellungen sind spezifisch für Substance Material mit einer Bildeingabe, die eine prozedurale Textur verwendet.
