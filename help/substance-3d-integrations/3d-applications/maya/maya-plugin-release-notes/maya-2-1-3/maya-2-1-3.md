# Mai 2.1.3

Veröffentlicht am 17. Juni 2020

Heute haben wir die Version 2.1.3 des Plugins veröffentlicht.

Version 2.1.3:

* Das Installationsprogramm ist jetzt mit SHA-256 unter Windows signiert
* Alle Binärdateien im Installationsprogramm sind jetzt unter Windows signiert
* substance\_link.dll und substance\_portal\_cli.dll verfügen jetzt über Versions-/Beschreibungsinformationen unter Windows
* Es wurde eine Workflow-Option für die Standardoberfläche im Mai 2020 hinzugefügt.

Diese Version wird für Mai 2017, 2018, 2019 und 2020 unter Windows, Linux und MacOS veröffentlicht. Es wird auch für Maya LT 2018, 2019 und 2020 unter Windows und MacOS veröffentlicht.
