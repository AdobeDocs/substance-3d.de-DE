# Mai 2.4.0

<b>hinzugefügt/aktualisiert:</b>

* Substance-Engine im Maya-Plug-in auf Version 9 aktualisiert, um Leistung und Kompatibilität zu verbessern.

<b>Fest:</b>

* Es wurde ein kritisches Problem im Mai 2023 behoben, durch das das Erstellen eines Netzwerks mit SBSAR-Dateien von Substance Engine Version 9 oder früher zum Absturz der Anwendung führte und eine stabile Netzwerkerstellung mit diesen Dateien sichergestellt wurde.

Maya 2.4.0 wird für Maya 2020, 2022 und 2023 unter Linux, macOS und Windows veröffentlicht
