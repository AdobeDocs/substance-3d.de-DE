# Redshift für 3ds Max

## Substance in 3ds Max Plugin

Das Substance-Plug-in unterstützt Redshift über die Render-Vorgabe von Redshift. Mit dieser Vorgabe werden die Substance-Ausgänge, die an ein Redshift-Material angeschlossen sind, automatisch eingerichtet.
