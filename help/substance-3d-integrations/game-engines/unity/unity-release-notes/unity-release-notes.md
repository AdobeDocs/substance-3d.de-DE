# Versionshinweise zu Unity

Wir unterstützen derzeit das Adobe Substance 3D Plugin für Unity ab der Unity 3.0.0 Version. Die Vorgängerversionen des Substance 3D-Plug-ins für ältere Versionen von Unity werden in Kürze deaktiviert.

**Unity-Versionen von 2.2.0 bis 2.6.0 werden in Kürze veraltet sein.**
