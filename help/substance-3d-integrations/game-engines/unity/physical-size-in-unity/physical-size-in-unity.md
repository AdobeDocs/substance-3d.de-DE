# Physische Größe in der Einheit

Die Physische Größe-Funktion im [Substance 3D](https://www.adobe.com/de/products/substance3d/3d-augmented-reality.html)-Plug-in für Unity ermöglicht das Anwenden und Skalieren von Substance-Materialien auf Basis ihrer tatsächlichen Größe. Die Abmessungen werden in Substance-Applikationen wie Designer festgelegt und im Abschnitt &quot;Physische Größe&quot; des Plug-in-Bedienfelds angezeigt.

Die Funktion ist derzeit nur für HDRP-Workflows verfügbar.

Wenn die Physische Größe aktiviert ist, werden die Materialien entsprechend ihrer tatsächlichen Größe in Zentimetern unterteilt. Die Kachelung des Materials bleibt unabhängig von der Größe des Objekts gleich.

Die Funktion kann aktiviert werden, indem Sie &quot;Physische Größe verwenden&quot; in der Benutzeroberfläche des Plug-in-Bedienfelds umschalten. Die Werte für die Physische Größe können zur künstlerischen Kontrolle über die Kachelung des Materials überschrieben werden.
