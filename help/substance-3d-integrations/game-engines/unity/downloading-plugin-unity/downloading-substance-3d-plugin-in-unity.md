# Substance 3D Plug-in in Unity herunterladen

## Medienelement-Store

Die Adobe Substance 3D für Unity ist im [Unity Asset Store](https://assetstore.unity.com/packages/tools/utilities/substance-3d-for-unity-beta-213208) verfügbar. Das Plug-in wird Ihrem Projekt im Ordner &quot;Assets&quot; hinzugefügt.

## Package Manager

Nachdem Sie das Plug-in über den Asset Store hinzugefügt und heruntergeladen haben, können Sie über den Package Manager (Unity 2020.3.27x und höher) unter **Meine Assets** auf das Plug-in zugreifen.

![](https://helpx-prod.scene7.com/is/image/HelpxProd/screen-shot-2022-03-29-at-10-45-20-am?$png$&jpegSize=300&wid=1920)

### Package Manager-Cache

Der Asset Store-Cache kann sich darauf auswirken, welche Version im Package Manager/unter &quot;Meine Assets&quot; verfügbar ist. Wenn Sie nicht die neueste Version erhalten, müssen Sie möglicherweise den Asset Store-Cache löschen.\
C:\Users\User Name\AppData\Roaming\Unity\Asset Store
