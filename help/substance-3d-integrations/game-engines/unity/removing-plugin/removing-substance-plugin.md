# Entfernen des Substance-Zusatzmoduls

Sie können die Substance-Material vor oder nach dem Löschen des Adobe-Ordners und der Adobe.meta-Datei entfernen.

1. Unity schließen. Unity muss geschlossen werden, um das Plugin zu entfernen. Wenn das Projekt geöffnet ist und das Plug-in entfernt wird, wird die Engine-DLL erneut importiert.
1. Navigieren Sie in einem Dateiordner zum Asset-Explorer und löschen Sie den Adobe-Ordner und die Adobe.meta-Datei.
1. Starten Sie Unity neu.
