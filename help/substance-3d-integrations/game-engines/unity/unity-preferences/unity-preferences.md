# Unity-Voreinstellungen

Im Einstellungsfenster von Adobe Substance 3D können Sie benutzerdefinierte Optionen für das Plug-in festlegen.

**Alle Diagrammausgaben generieren** - Generiert immer alle Diagrammausgaben pro Diagramm.

**Texturauflösung** - Standardauflösung für generierte Texturen pro Diagramm

**Maximale Auflösung der CPU** - Die maximale unterstützte Strukturauflösung bei Verwendung des CPU-Moduls.

**Substance 3D Assets** - Link zur Substance 3D Assets-Seite.

**Substance 3D-Community-Assets** - Link zur Substance 3D Community-Assets-Seite.

**Info** - Zeigt Informationen zur Plug-In-Version an.
