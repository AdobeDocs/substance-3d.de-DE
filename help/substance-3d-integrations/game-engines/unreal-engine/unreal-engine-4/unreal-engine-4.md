# Unreal Engine 4

![](../../../assets/ue4.jpg){width="800px"}

Die Substance in Unreal plugin kann vom [Unreal Marketplace](https://www.unrealengine.com/marketplace/en-US/slug/substance-plugin) heruntergeladen werden.

## Inhaltsverzeichnis

* [Übersicht über Plug-ins - UE4](https://helpx.adobe.com/substance-3d/unlisted/documentation/integrations/plugin-overview-185499723.html) - Übersicht über die Verwendung des Substance-Plug-ins in Unreal
* [Plug-In-Einstellungen - UE4](https://helpx.adobe.com/substance-3d/unlisted/documentation/integrations/plugin-settings-152535699.html) — Hier finden Sie die Einstellungen für das Substance-Plug-In in Unreal.
* [Substance-Eingabebild - UE4](https://helpx.adobe.com/substance-3d/unlisted/documentation/integrations/substance-input-image-152539035.html) — Substance kann mit Eingaben erstellt werden, bei denen Sie ein Bild zur Verarbeitung im Material bereitstellen können.
* [Materialinstanzdefinition - UE4](https://helpx.adobe.com/substance-3d/unlisted/documentation/integrations/material-instance-definition-157352129.html) - Sie können UE4 Materialinstanzen mit Substance verwenden.
* [Kacheln von Substance - UE4](https://helpx.adobe.com/substance-3d/unlisted/documentation/integrations/tiling-substance-159451177.html) — Um eine Substance-Textur zu kacheln, müssen Sie einen Texturkoordinatenknoten hinzufügen und diesen mit dem Skalarparameter multiplizieren.
* [Arbeiten mit Bump Offset (Parallax) - UE4](https://helpx.adobe.com/substance-3d/unlisted/documentation/integrations/working-with-bump-offset-parallax-159451180.html) — Wie Sie den Bump Offset-Knoten in Ihren Materialien verwenden können.
* [Arbeiten mit Versatz - UE4](https://helpx.adobe.com/substance-3d/unlisted/documentation/integrations/working-with-displacement-159451189.html) — Verwenden von Versatz mit Substance-Materialien
* [Quelle in UE4](../../../game-engines/unreal-engine/unreal-engine-4/source-in-ue4/source-in-ue4.md) — Sie können Materialien von der Quelle direkt in Unreal Engine herunterladen.
* [Live Link in UE4](../../../game-engines/unreal-engine/unreal-engine-4/live-link-in-ue4/live-link-in-ue4.md) — Senden von Texturen vom Substance Painter an Unreal
* [Blueprints - UE4](https://helpx.adobe.com/substance-3d/unlisted/documentation/integrations/blueprints-182256719.html) — Aktualisieren Sie Substance-Materialien zur Laufzeit mit einer umfangreichen Blueprint-API.
