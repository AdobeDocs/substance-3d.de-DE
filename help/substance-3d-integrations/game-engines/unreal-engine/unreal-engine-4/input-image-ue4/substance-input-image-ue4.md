# Substance Eingabebild - UE4

Substance kann mit Eingaben erstellt werden, in denen Sie ein Bild zur Verarbeitung im Material bereitstellen können. Auf diese Weise können Sie modulare Material erstellen, die Baking geführt Mesh-Daten oder -Muster als Eingabe verwenden, um das Material an das Asset anzupassen oder zu ändern. Um eine Textur als Substanzeingabe verwenden zu können, muss sie als Substance-Input-Textur in UE4 importiert werden.

1. Importieren Sie die Textur in den Inhaltsbrowser. Wählen Sie als Format Substance Image Input (jpg, tga, jpeg).
1. Diese Textur kann jetzt mit einem Substance-Eingang verwendet werden.
