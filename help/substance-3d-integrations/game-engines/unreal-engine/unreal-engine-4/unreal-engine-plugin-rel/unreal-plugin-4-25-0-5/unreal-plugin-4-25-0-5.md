# Unechtes Plug-in 4.25.0.5

Hinzugefügt:

* Unterstützung für Substance Engine 8.0.3
* Substance Source-Aktion greift jetzt auf die Registerkarte &quot;Quelle&quot; im Substance Launcher zu, sodass Assets direkt an UE4 gesendet werden können ([weitere Details](../../../../../game-engines/unreal-engine/unreal-engine-4/source-in-ue4/source-in-ue4.md))
* Weniger Substance-Materialien, die gleichzeitig beim Aktualisieren von Projektversionen verarbeitet wurden

Fest:

* UE4 stürzt unter Mac ab, wenn der Editor mit installiertem UE4 Substance-Plug-in geschlossen wird
* Das Ändern des Textparameters in einer Textinstanz führt zum Einfrieren und schließlich zum Absturz
