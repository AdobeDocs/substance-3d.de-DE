Dies ist eine Version für UE4.26-Kompatibilität.

Bekannte Probleme:

* Assets können nicht konsistent aus der Quelle in UE4 heruntergeladen werden. Umgehungslösung ist das Herunterladen von der [Substance Source-Website](https://source.substance3d.com/) und das manuelle Importieren der Assets.
