# Unechtes Plug-in 4.24.0.3

Substance in Unreal Engine wurde umfassend umstrukturiert. Ein Teil dieser Umstrukturierung bietet vollständige Unterstützung für **UTexture2D** und umfasst sowohl Eingänge als auch Ausgänge. Mit **UTexture2D**-Unterstützung kann das Plug-in jetzt für die Veröffentlichung auf jeder beliebigen Plattform verwendet werden. Unreal unterstützt auch mobile Plattformen. Zusammen mit der Unterstützung mehrerer Plattformen ermöglicht **UTexture2D** auch die native Verwendung des Textur-Streaming-Systems in UE4.

Das Plug-in bietet außerdem vollständige Unterstützung für Material **Instancing** und führt einen neuen Arbeitsablauf für Materialvorlagen mit numerischen Ausgaben ein, die vom Substance Engine unterstützt werden. Mit Materialvorlagen können Sie genau definieren, wie Sie Ihre Substance-Materialschattierungen in UE4 konfigurieren möchten.

![](../../../../../assets/ue4-material-templates.png)

Im Lieferumfang sind Vorlagen für die Arbeit mit Versatz, Brechung und Materialien mit Weltausrichtung enthalten, die integrierte Steuerelemente für die Anpassung von Kachelung, Texturgröße, Versatz und Emissionsparametern enthalten. Mit dem Materialvorlagensystem können Sie auch Ihre eigenen benutzerdefinierten Vorlagen bereitstellen.

![](../../../../../assets/ue4-material-instance-params.png)
