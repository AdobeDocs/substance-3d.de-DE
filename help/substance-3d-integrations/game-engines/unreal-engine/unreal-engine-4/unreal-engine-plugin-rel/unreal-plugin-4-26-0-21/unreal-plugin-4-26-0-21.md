# Unechtes Plug-in 4.26.0.21

Fest:

* Die Standardeinstellungen für den Substance-Import werden nicht auf Texturen angewendet, die aus einer Instanz erstellt wurden
* UE4 stürzt ab, wenn ein Gitter nach dem Löschen des Basismaterials an den Substance Painter gesendet wird
* Aktualisierungen der Komprimierungseinstellungen im UE-Editor werden nicht angewendet.
