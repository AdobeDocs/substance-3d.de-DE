# Unechtes Plug-in 5.3.2

Veröffentlicht am 4. Dezember 2023

<b>Fest</b>

* Es wurde ein Kompatibilitätsproblem mit dem Substance-Plug-in behoben, das unter Mac for Unreal Engine 5.3 nicht funktioniert.
* Es wurde ein Problem behoben, durch das das Deaktivieren eines Material-Kanals im Substance-Plug-in für Unreal Engine keinen Absturz mehr verursachte.
* Es wurde ein Problem behoben, bei dem im Material &quot;stone-arc.sbars&quot; im Plug-in nur Optionen für die Ausgabegröße im Abschnitt &quot;Eingabe&quot; angezeigt wurden, anstatt einen vollständigen Bereich von modifizierbaren Material-Eigenschaften anzuzeigen.
* Es wurde ein Problem mit der Farbverschiebung im Substance-Plug-in behoben, durch das importierte Materialien falsche, rot verschobene Normale und Off-Color-Grundzuordnungen anzeigten.
* Es wurde ein Absturz-Problem im Substance-Plug-in behoben, durch das bei Verwendung von &quot;Reimport&quot; unter einer .sbsar-Datei-Datei der Editor zum Absturz führte.
* Die Eingabevalidierung im Substance-Plug-in wurde verbessert, um Einträge außerhalb des Bereichs und ungültige Einträge in Schlüsselfeldern für Material-Eigenschaften zu verhindern.&quot;
* Es wurde ein Fehler behoben, durch den beim Erstellen einer zweiten Grapheninstanz im Substance-Plug-in alle zuvor geladenen Vorgaben entfernt wurden.&quot;
* Es wurde ein Problem behoben, durch das beim erneuten Importieren einer Substance Factory Instance alle vorhandenen Vorgaben entfernt wurden.
