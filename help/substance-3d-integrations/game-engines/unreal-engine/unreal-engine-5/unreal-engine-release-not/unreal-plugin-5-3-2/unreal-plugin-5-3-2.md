# Unechtes Plug-in 5.3.2

Veröffentlicht am 4. Dezember 2023

<b>Fest</b>

* Es wurde ein Kompatibilitätsproblem mit dem Substance-Plug-in behoben, das unter Mac für Unreal Engine 5.3 nicht funktioniert.
* Es wurde ein Problem behoben, durch das das Deaktivieren eines Materialkanals im Substance-Plugin für Unreal Engine keinen Absturz mehr verursachte.
* Es wurde ein Problem behoben, bei dem das Material &quot;stone-arc.sbars&quot; im Plug-in nur die Optionen &quot;Ausgabegröße&quot; im Abschnitt &quot;Eingabe&quot; anzeigte, anstatt einen vollständigen Bereich modifizierbarer Materialeigenschaften anzuzeigen
* Es wurde ein Problem mit der Farbverschiebung im Substance-Plug-in behoben, durch das importierte Materialien falsche, rot verschobene Normale und Off-Color-Grundzuordnungen anzeigten.
* Es wurde ein Absturzproblem im Substance-Plugin behoben, durch das bei Verwendung von &quot;Reimport&quot; bei einer .sbsar-Datei der Editor abstürzt.
* Die Eingabevalidierung im Substance-Plug-in wurde verbessert, um Einträge außerhalb des Bereichs und ungültige Einträge in wichtigen Materialeigenschaftsfeldern zu verhindern.&quot;
* Es wurde ein Fehler behoben, durch den beim Erstellen einer zweiten Graph-Instanz im Substance-Plugin alle zuvor geladenen Vorgaben entfernt wurden.&quot;
* Es wurde ein Problem behoben, durch das beim erneuten Importieren einer Substance Factory Instance alle vorhandenen Vorgaben entfernt wurden.
