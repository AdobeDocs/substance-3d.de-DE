# Unechtes Plug-in 5.0.1

Aktualisiert/hinzugefügt:

* Unterstützung für die Unreal Engine Version 5.0.0+
* Unreal Engine 5 Plugin Dokumentation
* Unterstützung der neuen Tri-planaren Materialschablone
* Unterstützung für die neue Funktion &quot;Physische Größe&quot;
* *Substance-Standardvorlage und Substance-Refraktionsvorlage überarbeitet*
* Die Möglichkeit, den XYZ-Wert für den Weltraum zu ändern
* Python-Skripterstellung
* Automatische Einstellung physikalischer Knoten der Materialgröße mit Werten aus den Substance-Ausgaben

Entfernt:

* Der Parameter &quot;float4&quot; im UE 5-Plugin

Fest:

* Verpacktes UE5-Projekt stürzt ab, wenn Materialparameter über Blueprints angepasst werden
* Plug-In schließt das Parameterfenster, wenn die Ausgabe der Substance-Grafen-Instanz deaktiviert ist
* Gelegentliche Renderverzögerung, die verzögerte Parameteränderungen verursachte, wurde behoben
