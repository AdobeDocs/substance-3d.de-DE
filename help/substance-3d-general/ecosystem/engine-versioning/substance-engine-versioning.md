# Substance-Engine-Versionierung

Auf dieser Seite werden Informationen darüber, welche Version der Substance-Engine in der jeweiligen Software und in den Tools verwendet wird, neu gruppiert.

Substance-Materialien und -Modelle, die mit der Substance-Software erstellt werden, können nur in Anwendungen verwendet werden, die die gleiche oder eine neuere Version der Substance-Engine unterstützen, da andernfalls neue Funktionen nicht kompatibel wären.

Die Tabellen auf dieser Seite zeigen Ihnen, ob ein Substance-Material oder ein Substance-Verfahrensmodell mit der aktuellen Softwareversion verwendet werden kann. Möglicherweise erwähnen sie nicht alle veröffentlichten Versionen, sondern nur diejenigen, bei denen ein Update durchgeführt wurde. Wenn also eine Version nicht erwähnt wird, bedeutet dies, dass die vorherige Version die zutreffende ist.
