# Substance Engine-Versionierung

Substance-Material und -Modelle, die mit Substance-Software erstellt wurden, können nur in Anwendungen verwendet werden, die dieselbe oder eine neuere Version des Substance Engine unterstützen.

Lesen Sie die folgenden Tabellen, um zu erfahren, ob ein Substance-Material oder ein prozedurales Substance-Modell mit der aktuellen Version Ihrer Software verwendet werden kann. In den Tabellen werden nicht alle Versionen für jede App aufgelistet, sondern nur die Versionen mit einem Update. Wenn also keine Version angegeben wird, wird weiterhin die vorherige Version des Substance Engine verwendet.

>[!NOTE]
>
> Um herauszufinden, welches Substance-Engine, welche Baker oder welche automatisch entpackt Version in Ihren installierten Apps verwendet wird, verwenden Sie **Hilfe > Info** und dann das Dropdown-Menü **Zusätzliche Informationen**, um eine vollständige Übersicht zu erhalten.
