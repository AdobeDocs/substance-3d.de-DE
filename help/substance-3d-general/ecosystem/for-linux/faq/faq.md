# Häufige Fragen

+++Was ist das neue ADA-Portal, und was kann ich damit tun?


Das ADA-Portal fungiert als zentraler Ort für die Verwaltung Ihrer Lizenzen und Zertifizierungen. Mit dem ADA-Portal können Sie:



* Aktuelle und frühere Lizenzen herunterladen

Aktuelle und frühere Lizenzen herunterladen

* Digitale Zertifizierungen abrufen und herunterladen.

Digitale Zertifizierungen abrufen und herunterladen.

* Fügen Sie Ihrem Konto zugeordnete Kontakte hinzu oder löschen Sie sie.

Fügen Sie Ihrem Konto zugeordnete Kontakte hinzu oder löschen Sie sie.

+++

+++Was kann ich tun, wenn ich die E-Mail mit der Bestellbestätigung nicht erhalten habe?


Überprüfe zuerst deinen Spam- oder Junk-E-Mail-Ordner, um sicherzustellen, dass die E-Mail nicht dort gelandet ist. Wenn du die E-Mail immer noch nicht finden kannst, wende dich an deinen Kundenbetreuer oder CSM.



+++

+++Wie installiere ich eine frühere Version der Software?
Ältere Versionen der Software durchsuchen und herunterladen:

* Öffnen Sie den Abschnitt Downloads von ADA.

* Klicken Sie auf &quot;Andere Versionen&quot;.

+++

+++Wie kann ich einen Kontakt hinzufügen oder löschen?


Hinzufügen eines Kontos:

* Öffnen Sie Ihre Kontakte über die Kopfzeile der Seite.

* Klicken Sie auf &quot;Kontakt hinzufügen&quot;.

* Geben Sie Kontaktinformationen ein.

* Klicken Sie auf Speichern.





So löschen Sie einen Kontakt:

* Öffnen Sie Ihre Kontakte über die Kopfzeile der Seite.

* Aktivieren Sie das Kontrollkästchen neben dem Kontonamen.

* Klicken Sie rechts auf der Seite auf &quot;Kontakte entfernen&quot;.



+++

+++Ich habe Probleme, mich beim Portal anzumelden. Was muss ich tun?


Wenn Sie eine Fehlermeldung bezüglich einer falschen E-Mail oder eines falschen Kennworts erhalten, stellen Sie sicher, dass Sie die richtigen Anmeldeinformationen verwenden, die mit Ihrem Konto verknüpft sind.





Wenn Sie einen anderen Fehlertyp finden, [wenden Sie sich an unseren Enterprise-Support](https://helpx.adobe.com/de/enterprise/using/support-for-enterprise.html).



+++

+++Wie kann ich meinen vorherigen Bestellungsverlauf sehen?
Der Bestellungsverlauf kann nur über das LWS-Portal aufgerufen werden. Zugriff auf das LWS-Portal:

* Rufen Sie die [Adobe-Lizenzierungs-Website auf.](https://licensing.adobe.com/)

* Melden Sie sich bei Ihrem LWS-Konto an.

* Klicken Sie auf Berichte.

* Wählen Sie &quot;Kaufverlauf anzeigen&quot;.

* Geben Sie Ihre Adobe-Bestellnummer ein.

* Klicken Sie auf Suchen.

[Weitere Informationen zu LWS finden Sie hier](https://helpx.adobe.com/de/x-productkb/policy-pricing/volume-licensing-site.html).



+++

+++An wen kann ich mich wenden, wenn ich weitere Hilfe benötige?
Wenn Sie weitere Unterstützung benötigen, können Sie sich an unser Enterprise-Support-Team wenden. Ihr Administrator muss sich [&#x200B; bei der Adobe Admin Console anmelden und einen Support-Fall öffnen](https://helpx.adobe.com/de/enterprise/using/support-for-enterprise.html).

Wenn Sie weitere Hilfe benötigen, können Sie sich an Ihren Adobe CSM wenden.
